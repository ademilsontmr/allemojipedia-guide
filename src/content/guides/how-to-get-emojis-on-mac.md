To get emojis on a Mac, click into any text field and press **Control + Command + Space**; on newer Mac keyboards you can instead press the **Globe key** (🌐, the same key as fn). If you prefer the mouse, choose **Edit > Emoji & Symbols** from the menu bar. Either way a small emoji picker opens at your cursor, and you type a word to find what you want.

The sections below cover the Globe key setting, the full Character Viewer, favorites, skin tones, your own emoji shortcuts and app-specific tricks. If you also use Windows, a phone or a Chromebook, our overview of [how to type emojis on any device](/guides/how-to-type-emojis-on-any-device/) covers those.

## Three ways to open the emoji keyboard on Mac

macOS has no on-screen emoji keyboard like an iPhone's. Instead, any app can call up one system-wide picker, and there are three ways to open it.

### 1. Control + Command + Space

This is the long-standing MacBook emoji shortcut, and it works on every Mac with every keyboard.

1. Click where you want the emoji to go, so the text cursor is blinking there.
2. Hold **Control** and **Command**, then press **Space**.
3. The picker appears just below or beside the cursor.

On a Windows-layout or other third-party keyboard, the key labeled Windows or Start normally acts as Command, so the combination becomes Control + Windows + Space.

### 2. The Globe key (or fn)

Apple's recent keyboards print a globe symbol on the fn key in the bottom-left corner. Press it once, on its own, and the emoji picker opens, provided the key is set to do that (see the next section). On older Apple keyboards the key just says fn; whether a single press opens emojis depends on the keyboard and your macOS version, so if nothing happens, use Control + Command + Space instead.

On recent versions of macOS, **Globe + E** (fn + E) also opens the picker, which is handy if you have assigned the single Globe press to something else.

### 3. Edit > Emoji & Symbols

Nearly every Mac app with text input has an Edit menu, and near the bottom of it is **Emoji & Symbols**. Choosing it opens the same picker. It is also a good test when the keyboard methods fail: if the menu item is missing or grayed out, the app or field you are in probably does not accept emoji input.

In many apps you can also right-click (or Control-click) inside a text field and find Emoji & Symbols in the shortcut menu.

## Set what the Globe key does

The Globe key is configurable, which is why it opens emojis on one Mac and switches languages on another. To check or change it:

1. Open the Apple menu and choose **System Settings** (called System Preferences on older versions of macOS).
2. Click **Keyboard** in the sidebar.
3. Find the menu labeled **Press 🌐 key to**.
4. Choose **Show Emoji & Symbols**.

The other options are **Change Input Source** (cycles through keyboard languages), **Start Dictation** and **Do Nothing**. If you type in more than one language, Change Input Source may already be selected, so pick whichever single-press action you use more and rely on Control + Command + Space for the other.

If you remapped modifier keys, look at the **Modifier Keys** settings under Keyboard Shortcuts in the same pane. A Globe or Control key that has been swapped with another key will break the shortcuts in this guide in confusing ways.

## Compact picker vs. Character Viewer

The window that pops up is two tools in one.

The **compact picker** is the small floating panel you see first. It shows a search field, a Frequently Used row and the emoji categories as small tabs along the bottom, such as smileys and people, animals and nature, food and drink, and flags. It closes as soon as you insert an emoji or click elsewhere.

The **Character Viewer** is the expanded version. To switch, click the expand button in the top-right corner of the compact picker. You get a larger, resizable window that stays open, with:

- a sidebar of categories, including Emoji, Favorites and symbol groups such as Arrows, Bullets/Stars, Currency Symbols, Letterlike Symbols and Math Symbols;
- a larger preview of whatever you select, with its official Unicode name;
- **Font Variation** previews showing the same character in other fonts;
- an **Add to Favorites** button.

To go back to the compact picker, click the same button in the top-right corner of the Character Viewer. macOS remembers which view you used last, so if the picker suddenly opens as a big window, that is why.

Use the compact picker for quick emojis in a chat. Use the Character Viewer for non-emoji symbols (a degree sign, an arrow), to read a character's official name, or to insert many characters without the window closing.

You can add more categories to the Character Viewer's sidebar, such as Pictographs or a full Unicode list, from its action menu (the gear or ellipsis button, depending on your macOS version), using the **Customize List** command.

## Search, navigate and insert faster

The single biggest time saver is to start typing the moment the picker opens. The search field is already active, so you do not need to click it.

- **Search by name or idea.** "Heart" lists every heart, "laugh" brings up the [face with tears of joy](/emojis/face-with-tears-of-joy/), "party" finds the [party popper](/emojis/party-popper/), and "check" returns the [check mark button](/emojis/check-mark-button/) along with other check symbols. The keywords come from Apple's emoji data, which is largely based on the Unicode CLDR project, so common synonyms usually work.
- **Move with the keyboard.** Use the arrow keys to move through the results, press **Return** to insert the highlighted emoji, and press **Escape** to close the picker without inserting anything.
- **Insert several in a row.** In the compact picker, inserting usually closes the panel. If you want three or four emojis, expand to the Character Viewer and double-click each one; the window stays open.
- **Browse by category.** If you do not know a name, click the category icons at the bottom of the compact picker. Our own category pages, such as [smileys and emotion](/categories/smileys-and-emotion/) and [symbols](/categories/symbols/), are another way to browse and then copy.

Searching for an emoji's look rather than its official name often fails. The [eyes](/emojis/eyes/) emoji is found under "eyes," not "side glance," and the [person shrugging](/emojis/person-shrugging/) is found under "shrug." When a search turns up nothing, try a simpler, more literal word.

## Favorites and frequently used emojis

The first row of the compact picker is **Frequently Used**. macOS fills it automatically from what you insert, so after a few days your regulars, perhaps the [thumbs up](/emojis/thumbs-up/), [red heart](/emojis/red-heart/) and [fire](/emojis/fire/), sit there without searching. The order shifts as your habits change.

For a list that does not move, use **Favorites**:

1. Open the picker and expand it to the Character Viewer.
2. Find the emoji or symbol you want and select it.
3. Click **Add to Favorites** below the preview.

Favorites appear in the Character Viewer's sidebar. To remove one, select it there and click **Remove from Favorites**. They are most useful for symbols you need at work, such as arrows or the euro sign.

## Skin tones and other variations

Hand and person emojis come in a default yellow plus five skin tones. On a Mac:

- In the **compact picker**, click and hold the emoji until a row of variations appears, then click the tone you want.
- In the **Character Viewer**, select the emoji and the available variations are shown alongside it.

macOS remembers your choice for that emoji, so the next time you insert the [waving hand](/emojis/waving-hand/) or [folded hands](/emojis/folded-hands/), the tone you picked is the one offered first. Some multi-person emojis, such as handshakes and couples, let you set each person's tone separately on recent versions of macOS. Background on how the five tones were chosen, and the etiquette questions people ask about them, is in our guide to [emoji skin tones](/guides/emoji-skin-tones-explained/).

## Make your own emoji shortcuts with text replacements

If you send the same emoji many times a day, a text replacement can be faster than any picker. You type a short code and macOS swaps it for the emoji.

1. Open **System Settings > Keyboard**.
2. Click **Text Replacements**.
3. Click the **+** button.
4. In **Replace**, type the code, for example `;ty`.
5. In **With**, insert the emoji or text, for example "Thank you 🙏". You can open the emoji picker right inside this field.
6. Click **Add** (or press Return).

A few tips that make replacements work well:

- **Start codes with a character you rarely type**, such as a semicolon or a double letter, so the replacement never fires by accident inside an ordinary word. `;fire` is safer than `fire`.
- **Use Slack-style codes if you already know them.** Setting `:shrug:` to the shrug emoji or `:100:` to the [hundred points](/emojis/hundred-points/) symbol means the same habit works on your Mac and in your chat apps.
- **Replace with combinations, not only single emojis.** A code like `;yay` can produce 🎉✨🙌.
- **Expect them on your other devices.** Text replacements sync through iCloud to an iPhone or iPad signed in to the same Apple Account, as long as iCloud syncing is on.

Replacements work in most apps that use Apple's standard text system, including Notes, Mail, Messages, Pages and Safari. Some apps built on other frameworks, including certain chat and code editors, ignore them.

## Emojis in Messages, Mail, Notes, Slack and browsers

The system picker works almost everywhere, but some apps add their own options.

**Messages.** Control + Command + Space works in the message field as usual. Messages also has Tapback reactions: Control-click or hover over a bubble to react. On recent versions of macOS, Tapbacks are not limited to the classic six symbols, and you can react with any emoji from the picker.

**Mail.** Emojis are fine in the subject line and the body; use the shortcut or Edit > Emoji & Symbols. Remember that the recipient's mail program draws the emoji, so it may look different or, in old corporate software, show as a box. If you write work email, our [emoji etiquette guide for work](/guides/emojis-at-work-etiquette/) covers where they help and where they do not.

**Notes, Pages, TextEdit and Keynote.** The picker works everywhere you can type. In documents, an emoji takes on the size of the surrounding text, so increase the font size if you want a big emoji on a slide.

**Slack, Discord, Teams and GitHub.** These apps have their own emoji systems. Type a colon followed by a few letters, such as `:thumb`, and an autocomplete list appears. The Mac picker still works in their message fields, and in Slack and Discord it inserts the standard emoji character. Shortcode names vary by app, so `:joy:` may work in one and not another.

**Safari, Chrome and Firefox.** In web forms and web chat apps, the shortcut and the Edit menu behave as in any native app. Some sites block emojis in fields such as usernames, and older sites may turn them into question marks on submit.

**Copy and paste from the web.** An emoji is ordinary text, so you can copy it from any page, including the individual emoji pages here such as [sparkles](/emojis/sparkles/), and paste it wherever you want.

On Macs that support Apple Intelligence, recent versions of macOS can also create Genmoji, custom emoji-style images made from a description. These are sent as images, not standard emoji characters, so recipients on other platforms may not see them inline.

### MacBook Pro models with a Touch Bar

Some MacBook Pro models have a Touch Bar, a thin touchscreen strip in place of the function keys. In apps that support typing suggestions, such as Messages, Mail and Notes, the Touch Bar can show an emoji button. Tap it and a scrollable row of emojis appears on the strip; tap one to insert it.

The Touch Bar row has no search box, so the keyboard shortcut is still faster for anything specific. If the emoji button is missing, check the Touch Bar settings under **System Settings > Keyboard** and make sure typing suggestions are turned on.

## When the emoji picker will not open, or emojis look wrong

Most problems have a short list of causes. Work through them in order.

1. **The cursor is not in a text field.** The picker only opens where you can type. Click into the field first, then press the shortcut.
2. **The Globe key is set to something else.** Check **Press 🌐 key to** in System Settings > Keyboard, as described above.
3. **You are on a third-party keyboard.** The Globe key will not work; use Control + Command + Space, remembering that the Windows key acts as Command.
4. **Another app took the shortcut.** Launchers, window managers and some games register their own global shortcuts. Quit recently installed utilities and try again, or use the Edit menu.
5. **The app does not support it.** Some games, full-screen video apps and apps with custom text fields ignore the system picker. Type the emoji somewhere else and paste it in.
6. **The picker is stuck.** Close it with Escape, quit and reopen the app, and if that does not help, log out and back in or restart the Mac.

If the picker opens but emojis come out wrong, the cause is usually on the display side, not the input side:

- **A box or a box with a question mark** means the emoji is newer than your macOS. Update in **System Settings > General > Software Update**. New emojis reach the Mac in the macOS update that pairs with the matching iPhone release; [new emojis in 2026](/guides/new-emojis-2026/) lists the most recent ones.
- **Two emojis where one was intended** means a combined sequence your system or the recipient's does not support. The full explanation is in [why emojis show as boxes](/guides/why-emojis-show-as-boxes/).
- **A black-and-white symbol** instead of a color emoji usually means the character was inserted from a text font or lost its emoji style. Delete it and insert it again from the emoji picker.
- **It looks different to the other person.** Apple, Google, Samsung and Microsoft each draw their own art. See [iPhone vs Android emojis](/guides/iphone-vs-android-emojis/) for what changes between them.

## Quick reference: Mac emoji shortcuts

| What you want | How to do it on a Mac |
|---|---|
| Open the emoji picker | Control + Command + Space |
| Open it with one key | Globe key, if set to Show Emoji & Symbols |
| Alternative Globe shortcut | Globe + E (fn + E) on recent macOS |
| Open it without the keyboard | Edit > Emoji & Symbols, or right-click a text field |
| Search | Start typing as soon as the picker opens |
| Insert the highlighted emoji | Return |
| Close without inserting | Escape |
| Expand to the Character Viewer | Button in the picker's top-right corner |
| Pick a skin tone | Click and hold the emoji |
| Save a favorite | Character Viewer > Add to Favorites |
| Create your own shortcut | System Settings > Keyboard > Text Replacements |
| Change the Globe key's action | System Settings > Keyboard > Press 🌐 key to |
| Shortcodes in Slack or Discord | Type a colon and a few letters, such as `:fire` |

A good rule of thumb: learn Control + Command + Space first, because it works on every Mac and every keyboard. Then set the Globe key the way you like, add two or three text replacements for the emojis you send constantly, and keep macOS up to date so the newest emojis appear in your picker instead of as boxes. If you also own a [laptop](/emojis/laptop/) running Windows, or want to send emojis on your phone, the [all-device guide](/guides/how-to-type-emojis-on-any-device/) has those shortcuts side by side.

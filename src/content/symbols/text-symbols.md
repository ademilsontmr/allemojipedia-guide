## What text symbols are

Every symbol on this page is a Unicode character, the same kind of thing as the letter A or the number 7. It is not an image. When you paste ✓ into a document, the font on your screen draws it, so it picks up the font's color, size and weight. Make the paragraph red and the checkmark turns red; switch to bold and it gets heavier. That is the main reason people reach for text symbols instead of emoji: they blend into ordinary writing.

Unicode assigns every character a number and an official name, and the [Unicode code charts](https://www.unicode.org/charts/) list them all. Fonts then decide what each character looks like, which is why ★ is a little different in a Mac document, a Windows spreadsheet and an Android chat. The shape changes, the meaning does not.

### Text symbols and emoji

Emoji are Unicode characters too, but most of them are drawn as small color pictures. Some older symbols sit on the line between the two. Characters like ❤ ☀ ✔ and the zodiac signs have both a text style and an emoji style, and Unicode lets a hidden marker after the character request one or the other. Not every app or operating system follows that request, so the same character can look like a plain black symbol on one device and a color emoji on another. If you need a guaranteed picture, use an emoji from the [emoji copy and paste page](/emoji-copy-and-paste/). If you need something that matches your text, pick a symbol that has no emoji version, such as ✓ instead of ✔.

## Which symbols work where

Symbols are text, so they go anywhere text goes, but some places handle them better than others.

| Where | Good choices | Watch out for |
|---|---|---|
| Documents and slides | ✓ ✗ • → © ™ – — | Arrows and bullets may look different if the file opens in another font |
| Social media bios | ★ ♡ ✦ → • 「 」 | Long decorative strings are hard to read and to hear with a screen reader |
| Usernames and handles | Usually none | Most services allow only letters, numbers, periods and underscores |
| Gaming names | ★ ♛ † 【 】 | Many games filter or reject symbols; test the name first |
| Spreadsheets | ✓ ✗ ↑ ↓ ± ° € £ | A symbol in a number cell turns it into text, which breaks math |
| Chats and texts | ♪ ☀ ♡ → | Some symbols switch to emoji style on phones |

## How to type symbols on Windows

Copy and paste is the fastest route for anything unusual, but Windows has two built-in ways to type common symbols.

**The emoji panel.** Press the Windows key + period (.) to open the panel. On recent versions of Windows it has a symbols tab, marked with an Ω, with punctuation, currency, math, Latin and other groups. Click a symbol to insert it at the cursor.

**Alt codes.** On keyboards with a numeric keypad, turn on Num Lock, hold Alt, type the code on the keypad (not the number row), and release Alt. A few reliable ones:

- Alt+0169 gives ©
- Alt+0174 gives ®
- Alt+0153 gives ™
- Alt+0176 gives °
- Alt+0177 gives ±
- Alt+0150 gives – (en dash) and Alt+0151 gives — (em dash)

Alt codes do not work from the number row along the top of the keyboard, which is why many laptops cannot use them. Windows also includes Character Map, which you can find by searching for it in the Start menu, for browsing every character in a font.

## How to type symbols on a Mac

Macs put many symbols on the keyboard behind the Option key. With the standard US layout:

- Option+G gives ©
- Option+R gives ®
- Option+2 gives ™
- Option+8 gives •
- Shift+Option+8 gives °
- Option+hyphen gives – and Shift+Option+hyphen gives —
- Option+semicolon gives …
- Option+equals gives ≠

For everything else, press Control+Command+Space to open the Character Viewer. Click the expand button in its corner to browse categories such as arrows, bullets and stars, currency symbols, and math symbols, or type a name like "arrow" into the search field. The Mac emoji guide, [how to get emojis on a Mac](/guides/how-to-get-emojis-on-mac/), walks through the same viewer in more detail.

## How to type symbols on iPhone and Android

Phone keyboards hide extra characters behind long presses. On the iPhone keyboard, switch to numbers and long-press the hyphen for dashes and a bullet, the dollar sign for other currency signs, and the quotation marks for curly and angled quotes. Gboard on Android also offers extra characters on long press and on its symbols pages; the exact layout depends on the keyboard version.

For symbols you use often, set up a shortcut so a short code expands into the symbol:

- **iPhone:** Settings > General > Keyboard > Text Replacement. Paste the symbol as the phrase and choose a shortcut, such as "chk" for ✓.
- **Android:** Gboard's personal dictionary lets you add a word with a shortcut that suggests it as you type.

The guide to [typing emojis on any device](/guides/how-to-type-emojis-on-any-device/) covers the keyboard settings for each platform.

## Why a symbol shows as a box

If a symbol turns into an empty rectangle, a box with a question mark, or a box with a code inside it, the font on that device has no drawing for that character. The character arrived correctly; there is just nothing to show. Older phones and computers, minimal fonts in some apps, and games with their own fonts are the usual causes. Every symbol on this page was chosen because it displays on current iPhone, Android, Windows and Mac systems, but a reader on an old device may still see boxes. The full explanation and fixes are in [why emojis show as boxes](/guides/why-emojis-show-as-boxes/).

## Symbols and screen readers

Screen readers such as VoiceOver, TalkBack and NVDA read most symbols aloud by name. A single → or ✓ reads fine. A name decorated as ★彡 or a bio line built from twenty hearts is read one character name at a time, which is slow and tiring to listen to. Some symbols are read by a name that does not match how you are using them, so a ✗ meant as "no" may be announced as a ballot X.

A few habits keep symbol use friendly:

- Use one symbol where you might use five.
- Do not rely on a symbol alone to carry meaning; write "Done ✓" rather than just "✓".
- Keep decorative symbols out of usernames people need to type or search for.

If you are unsure what a symbol is called or what it means, look it up the same way you would an emoji on [what does this emoji mean](/what-does-this-emoji-mean/).
